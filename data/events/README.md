# Event and shrine reference

This directory is an offline A0 implementation reference for the 51 standard
events and shrines plus Neow. It is not a runtime registry, a statement that the
simulator implements these branches, or validation against the original game.

## Files and fields

- `annotations.json` is the editable source record. Each event has its Rust
  identity candidate and grade, display name, acts, pool, eligibility rule and
  branches. Branches separate `amounts`, `draws`, and player or nested
  `selections`; each fact carries a grade where it can differ from the branch
  grade. `citations` point to repository lines or captured wiki page revisions.
  `decisions` lists the applicable E0–E15 and F1–F8 project decisions.
- `events.json` is generated from the annotations and checked local source files.
  It adds the page/revision set used by each record and a SHA-256 manifest of the
  repository snapshots and research files read by the builder.
- `sources/` contains unchanged version 2 and version 3 wiki captures and their
  retrieval and attribution records.
- `build_dataset.py` reads repository files only. It checks citation paths and
  captured revisions, then generates stable UTF-8 JSON. `--check` compares the
  generated bytes with `events.json` without writing it.
- Cited local research remains under `docs/research/` and is referenced by exact
  repository path and line. A captured page supports only the community-wiki
  claim at that page revision.

## Grades and limits

`S` is a static source inspection or source-grounded local research; `BC` is a
checked bytecode correction recorded by that research; `D` is arithmetic from a
sourced formula; `W` is captured community-wiki wikitext; and `U` means the
allowed source set does not settle the value. Every `U` branch includes a note
and an E/F number. Candidate source IDs for Act 2 and Act 3 remain provisional
under E1. A Rust identity is not proof of a canonical game constructor ID.

Most local static event research covers Ironclad A0. E0 records the project
assumption that event bodies are shared across characters except where they read
character data; it does not upgrade those source grades or establish original
cross-character parity. Character-dependent values and branches remain scoped
to their cited evidence. Unknown amounts, draw laws, candidate IDs and branches
are marked `U`; no amount is inferred from an unsourced integer convention.

Damage and healing amounts are requests through their cited pathways, not
guaranteed net HP changes after prevention, rescue, caps, or death. Random laws
describe only what the cited source establishes; these records do not claim
seeded Java RNG or history-conditioned distribution parity. Wiki pages are
community-authored and may be inaccurate. Captured pages and local reports do
not establish original-runtime behavior.

## Checks

Run from the repository root:

```sh
python3 -B -m unittest tests/python/test_events_reference.py -v
python3 -B data/events/build_dataset.py --check
```

These checks cover the offline record, citations, source containment and byte
reproducibility. They do not test the simulator's event behavior.

# M28 events and economy coverage ledger

Gate audit against M28 design §§4–6, 12, 14 and plan Task M3, on the M28f2 tree. `data/events/events.json` contains 52 records and 145 branch rows. **Constructed** means a named constructed-state Rust test, **Supplied** a `StandardA0` Run with supplied state, and **Traversal** a seeded random-policy `StandardA0` Run. **W-graded value** keeps the source grade of the captured wiki and does not upgrade the test grade. A shape-only guard is not a branch-value pin. "n/a" in a per-character cell means the branch reads no character data, so E0 requires no per-character case. The six accepted events (Upgrade Shrine, Purifier, Ancient Writing, The Joust, Tomb of Lord Red Mask, Falling) reuse their M5–M8 handlers (design §5.5) and cite those milestones' tests.

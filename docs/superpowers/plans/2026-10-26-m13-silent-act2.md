# M13 Silent through Act2 Implementation Plan

> **For agentic workers:** REQUIRE approval of the reviewed design and plan in the primary session before implementation. Use the milestone's authorized execution method after that approval; one fresh independent milestone review occurs after the integrated source is frozen.

**Goal:** Add a finite normal-start Silent A0 Run through Act2 to actual Act3Ready, with versioned native session, observation, replay and batch support.

**Architecture:** Extend the authoritative shared `Run` and its existing Act1/Act2 room, combat and transition owners. Keep M12 immutable at Act2Ready, compose its captured Silent rows with shared Act2 captures, and add distinct M13 identities using the existing environment and codec owners.

**Tech Stack:** Rust workspace (`spire-core`, `spire-env`); locked offline Cargo lane.

**Spec:** `docs/superpowers/specs/2026-10-26-m13-silent-act2-design.md`

## Global Constraints

- M13 is Silent A0 from canonical normal start through actual Act2 and Act3Ready (Act3/floor34); no Act3 decision is accepted.
- Keep M9/M10/M12 profile IDs, old boss-history spellings, observation IDs/fingerprints, M12’s Act2Ready cutoff, and the shared Run/combat owners stable.
- `RunSessionConfig` keeps its one `boss_history` field; M13 adds one typed composite history variant for an Act1 and an Act2 boss target before Run construction.
- The finite permanent/relic/potion catalog is the accepted M12 19/13/4; Wound is the only added generated card identity. Publish 21 distinct Act2 enemies and 12 Act2 encounter IDs, with all reachable powers, intents, events, choices, rooms, selections and the Act3 map-only boss icon.
- The Act2 shop uses Act2-local `shop_visits`; its first visit uses the first M12 finite shop row and later visits use the later row. Elite relic cursors reset by act and skip already-owned relics. A successful offer commits its next cursor with the published reward screen even if the player proceeds without selecting it; an exhausted lookup errors without a new advance.
- Freeze the six seed/boss pairs from the spec before running them. Normal evidence uses only public observations, visible map topology, legal actions and offered choices; no injected later state, seed search, enemy edits or policy tuning after outcomes.
- Natural Death, caller budget exhaustion, unsupported content exhaustion, operational fault and Act3Ready remain distinct. Boss coverage requires actual Act2 boss entry for each target and at least one normal-start boss Victory through real boss reward/chest to Act3Ready.
- This is native Rust delivery only. Do not claim full Silent pools, original-runtime execution, Java RNG/map parity, Python extension delivery or full target completion; M15 owns complete Silent A0 closure or an explicit blocker.
- The preserved workspace baseline is 1,529 passed plus the historical Blue Slaver setup failure; scoped or full runs must retain revision-qualified failure reporting.
- The assigned M13 execution child has no commit, push, install or cleanup authority; leave integration decisions to root.

## Review Focus

1. **Inherited mutable source:** an approved plan or changing M15 API must not become fictional accepted behavior, nor overwrite an accepted prefix. Task0 binds exact source; Task1 tests prefix equivalence and old cutoffs.
2. **Sparse/half-dead/replaced actors:** cap10 orbs, Dark target construction and real revival/partner/summon lifetimes must preserve source semantics and per-hit damage categories. Task2 pins these combinations, including HalfDead not being synonymous with dead/escaped.
3. **Accepted repeated-card interruption:** TimeWarp, Curiosity, learned misc, permanent gains and source faults must not drop an accepted parent, recursively replay work or settle twice. Tasks2/4 pin the actual callbacks and custody.
4. **Finite-stock and ending boundaries:** prior owned relics, skipped offers, Falling twins, key choices and real boss50 dialogs must keep correct cursors/resources and terminal/cutoff distinctions. Tasks1/3/4 test these without supplied evidence replacing normal traversal.
5. **Foreign/malformed public transport:** duplicate/partial triple history, hidden state, insufficient capacity, stale token/reset and peer preflight must fail explicitly while preserving accepted work and frozen old contracts. Tasks4/5 own these checks.

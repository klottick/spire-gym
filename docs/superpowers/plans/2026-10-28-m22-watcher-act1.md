> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans only after actual primary approval, accepted M21 source and root release. One senior implementation owner, meaningful TDD and one fresh independent final milestone reviewer; no per-task review swarm. This document is planning only.

**Goal:** Canonical native Watcher A0 Act1 progression through actual combat, rooms, rewards and boss exchange to healthy nonterminal Act2Ready, preserving genuine Deaths.

**Architecture:** Extend shared Run/content/item/combat owners and the existing versioned encoder, native RunSession, replay codec and ordered batch scheduler. Consume accepted M21 mechanics and staged startup. One finite content module supplies producer rows; no copied progression, encounter inventory, resolver, journal or session loop.

**Tech Stack:** Existing locked Rust workspace, serde/JSON, native int64 observation transport and checked Run RNG. No dependencies, Python refresh or original-game execution.

**Spec:** [M22 design](../specs/2026-10-28-m22-watcher-act1-design.md). Read both; exact acquisition rows, capture law, resources, identities and evidence limits are fixed there as proposals pending review/primary approval.
